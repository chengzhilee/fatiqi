# 罚题器 · 使用说明

本地刷题工具：把试卷 PDF / Word 上传进去，自动拆题、提取答案，然后多套卷混合随机抽题、倒计时刷题。
所有数据都存在你自己电脑上，不联网也能用。

## 怎么启动

**双击「启动罚题器.bat」** —— 会自动打开浏览器进入刷题页面。

- 关闭方法：直接关掉那个黑色命令行窗口即可。
- 如果页面提示"未连接服务"，说明黑窗口没在运行，重新双击 bat 就行。
- 同一个 bat 重复双击没关系：检测到已在运行时只会再开一个页面。

## 怎么用

### 1. 上传试卷（题库页）
把 PDF 或 Word 试卷**拖进上传框**（或点击选择文件），然后：
- 选好存入的类别（如"大学生数学竞赛"）、填套卷名称（默认取文件名）；
- 点「① 提取题目」—— 自动把试卷按题号拆开、并把答案区的答案对应到每道题；
- 在校对列表里粗查一遍（自动识别的数学符号可能有出入，可直接改），点「② 保存入库」。

保存后，这套卷的原卷 PDF/Word 会以"📄 原卷附件"形式贴在套卷旁边，**随时点击就能打开原卷**。

**两种进阶提取方式（PDF 都可用）：**
- **✂️ 按原卷切图（推荐公式多的卷子用）**：把每道题的区域直接裁成原图贴进题库，
  公式、图形、表格 100% 原样，彻底绕开文字识别误差；文字版 OCR 结果会作为备注一起保存。
  校对时看一眼每张切图，切坏的删掉即可。
- **🔍 OCR 文字识别**：把每页用 Windows 自带离线 OCR 认成文字再拆题，适合想要
  可编辑文字的场景，但公式误差较大。

**切图切坏了怎么办（编辑题目 → ✂️ 调整切图）：**
- 在原卷上**点两下**（本题开头的上边缘、结尾的下边缘）→ 点「设为题干图」或「设为答案图」；
- 两道题被切进同一张图 → 点两下框住其中一道 → 点「↪ 拆为新题」；
- 一道题被切成两张 → 打开第二张的编辑页 → 点「⬆️ 并入上一题」；
- 可以上下翻页找内容。改完记得点「保存」。

### 2. 罚题（开始罚题页）
- 勾选要做的**几套卷**（可多选，比如第 16 届和第 17 届一起）；
- 选**题目数量**（如 3 道）—— 从所选套卷里**随机抽**，可能全部来自同一套；
- 选**总时长**（分钟，填 0 不限时）—— 时间一到自动交卷；
- 答题时点「显示答案」对照，自己判"答对/答错"，最后看统计，还能**只重刷错题**。

## 类别与数据

- 默认有"大学生数学竞赛""四级英语"两个类别，可以自己新建/删除。
- 题目数据在 `data\` 文件夹，上传的原卷在 `uploads\` 文件夹。
- **备份 = 复制这两个文件夹**；想清空重来也是删它们。

## 已知限制

- 老版 `.doc` 无法自动拆题（会提示），建议另存为 `.docx` 或 PDF 再传；附件本身仍可保存。
- 扫描版 PDF（整页是图片）或**文字层损坏的 PDF**（提取出来是乱码，部分软件导出 PDF 的通病）
  提不出文字：用「✂️ 按原卷切图」或「🔍 OCR 文字识别」都可以处理，无需联网。
- 自动切图偶尔会切错（漏题号、边界切偏）：编辑题目里用「✂️ 调整切图」点两下就能修好，
  详见上文"切图切坏了怎么办"。
- OCR 文字版的公式误差较大；**切图版没有这个问题**（原图直出）。做题以切图/附件原卷为准。

## 技术备注（给自己看的）

- 便携 Python 在 `runtime\`，删项目时整个文件夹一起删即可；不用安装任何东西。
- 端口占用 8765–8775 自动顺延；界面用 file:// 方式打开以绕过本机安全软件对 127.0.0.1 网页的拦截。
- OCR 用的是 Windows 自带能力（`ocr.ps1` 调 Windows.Media.Ocr，离线），题目渲染和拆题都在浏览器里完成。
- `test\` 里是开发期的测试文件，不影响使用，想删也行。
