一、填空题
1. 4。
2. 3。
3. 2xy + y·e^(xy)。
4. y = C₁cos2x + C₂sin2x（C₁, C₂ 为任意常数）。
5. R = 1。
二、解答题
6. 解：y′ = 3x² − 6x，y″ = 6x − 6。令 y″ = 0 得 x = 1。当 x < 1 时曲线上凸，x > 1 时下凸（凹），拐点为 (1, −1)。
7. 解：化为二次积分，∫₀¹ dx ∫(x²→1) (x + y) dy = ∫₀¹ [x(1 − x²) + (1 − x⁴)/2] dx = 4/5。
8. 证：设 f(x) = e^x − 1 − x，则 f′(x) = e^x − 1 > 0（x > 0），又 f(0) = 0，故当 x > 0 时 f(x) > 0，即 e^x > 1 + x。
9. 解：|A| = 1 × 2 × 3 = 6，故 |A²| = |A|² = 36。
10. 解：齐次方程通解为 y = (C₁ + C₂x)e^x。设特解 y* = ax²e^x，代入得 a = 1/2。由 y(0) = 1 得 C₁ = 1，y′(0) = 0 得 C₂ = 0。故特解 y = (1 + x²/2)e^x。
